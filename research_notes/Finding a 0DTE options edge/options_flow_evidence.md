# Options order flow and off-exchange prints as short-horizon predictors for SPY/QQQ/IWM (evidence note)

Scope: published, working-paper, exchange and vendor evidence on whether signed option flow, sweeps/"unusual" prints, per-strike premium bursts, net premium ("market tide"), NOPE/net delta, and dark-pool prints predict minutes-to-one-session returns of US index ETFs/indices and of the options themselves; plus what is testable with the Unusual Whales (UW) endpoints we can call by date. Evidence class is tagged on each item: [PR] peer-reviewed, [WP] working paper, [EXCH] exchange research, [VENDOR] vendor/practitioner claim, [REPO] this repository's own audit. Anything sampled before May 2022 pre-dates daily SPX/ETF expirations; anything on single stocks is flagged.

Cost-arithmetic sections are my own calculations from stated assumptions (not citations).

## KQ0. What is each signal supposed to capture, and how exactly is it constructed?

### Takeaway
Every signal in scope is a signed-aggressor aggregate of OPRA/TRF prints: it assumes "at/near ask = customer buy, at/near bid = customer sell", then weights by premium, volume or delta and sums over contracts, strikes or the whole market. None of the vendor constructions observes who the counterparty is or whether a trade opens or closes a position; the academic constructions that do predict returns (Pan–Poteshman, Ni–Pearson–Poteshman–White) rely on CBOE/OCC origin and open/close codes that are not in OPRA.

### Cited Findings
- UW market tide: "Net call premium = call premium at the ask minus call premium at the bid"; same for puts; net volume = (call ask-side vol − call bid-side vol) − (put ask-side vol − put bid-side vol); "Transactions taking place at the mid are not accounted for"; market-wide, 1-minute default with `interval_5m` and `otm_only` flags; `date` history "goes back to 2022-09-28" — [UW market-tide docs](https://api.unusualwhales.com/docs/operations/PublicApi.MarketController.market_tide) [VENDOR]
- UW's underlying NetFlow stream is "the ask-side and bid-side volume and premium of all option trades", published as per-interval deltas at 1-minute and 1-second resolution — [UW Kafka NetFlow type](https://api.unusualwhales.com/docs/kafka/types/NetFlow) [VENDOR]
- UW `stock/{t}/net-prem-ticks`: "Each tick is resembling the data for a single minute tick. To build a daily chart you would have to add the previous data to the current tick"; sample code uses `net_call_premium`, `net_call_volume`, `net_put_premium`, `net_put_volume`; field schema not documented in the public mirror — [UW API docs mirror, net-prem-ticks](https://github.com/DigiBugCat/unusual-whales-api-docs/blob/main/docs/stock/stock-net-prem-ticks.md) [VENDOR]
- UW `stock/{t}/flow-per-strike-intraday`: "Returns the options flow for a given date in one minute intervals" that "are not aggregated with each other"; takes `date` and `filter`; response fields undocumented in the mirror — [UW API docs mirror, flow-per-strike-intraday](https://github.com/DigiBugCat/unusual-whales-api-docs/blob/main/docs/stock/stock-flow-per-strike-intraday.md) [VENDOR]; our own audit observed per-strike call/put premium and volume by ask/bid side per minute, 2,484 rows/day for SPY — [DATA_PROVIDER_AUDIT.md](/home/user/georgeredo/DATA_PROVIDER_AUDIT.md) [REPO]
- UW `option-contract/{id}/intraday`: 1-minute candles with `open/high/low/close/volume/bid/ask/iv` per the mirror — [UW API docs mirror, intraday](https://github.com/DigiBugCat/unusual-whales-api-docs/blob/main/docs/option-contract/intraday.md); our audit observed ask/bid/mid-side premium and volume plus `iv_high/iv_low`, 390 rows per RTH day, historical dates work — [DATA_PROVIDER_AUDIT.md](/home/user/georgeredo/DATA_PROVIDER_AUDIT.md) [REPO]
- UW `darkpool/{t}`: "Returns the darkpool trades for the given ticker on a given day"; example fields `price, size, premium, volume, nbbo_bid, nbbo_ask, nbbo_bid_quantity, nbbo_ask_quantity, executed_at, market_center, ext_hour_sold_codes, sale_cond_codes, trade_settlement, canceled`; the docs do not name the data source (TRF/ADF) or say whether prints are ATS-only or all off-exchange — [UW API docs mirror, darkpool-ticker](https://github.com/DigiBugCat/unusual-whales-api-docs/blob/main/docs/darkpool/darkpool-ticker.md) [VENDOR]
- UW `option-trades/flow-alerts` documented response fields: `alert_rule`, `has_sweep` ("Whether trade included sweep orders"), `all_opening_trades`, `volume_oi_ratio`, `total_premium`, `trade_count`; `has_floor`, `has_multileg`, `has_singleleg`, `total_ask_side_prem`, `total_bid_side_prem` appear only in the example; request filters `is_ask_side`/`is_bid_side`/`is_sweep`/`is_floor`/`all_opening` exist but "the document does not explain how a trade is classified as ask-side, bid-side, mid, or no-side" — [UW API docs mirror, flow-alerts](https://github.com/DigiBugCat/unusual-whales-api-docs/blob/main/docs/option-trades/flow-alerts.md) [VENDOR]
- UW's own "Net Premium" explainer: ask-side calls and bid-side puts push the overall line up (bullish), ask-side puts and bid-side calls push it down; "transactions at the ASK are not necessarily BUYS, nor are transactions at the BID necessarily SELLS"; a worked JBLU example (Mar 2024) shows a −$443k "bearish" net-premium print that was a position closure, confirmed by the next day's OI drop — [UW Substack, Net Premium tool](https://unusualwhales.substack.com/p/how-to-use-the-net-premium-tool-on) [VENDOR]
- UW alert rules: Repeated Hits groups same-chain trades within 100 ms, excludes multi-leg and floor, fires if >5 transactions and premium > $10K (small caps) / $50K (> $50B) / $100K (> $500B); Ascending/Descending Fill variants add a price-path condition; "Sweeps Followed By Floor" = ≥10 sweeps then a ≥$100K floor trade; a sweep is "a market order, typically larger in size, that sweeps different exchanges"; the post makes no predictive-performance claims — [UW Substack, flow alert breakdown](https://unusualwhales.substack.com/p/a-breakdown-of-every-type-of-flow) [VENDOR]
- UW screener ("Hottest Chains") fields seen proxied by GeorgeFi: `days_of_oi_increases`, `days_of_vol_greater_than_oi`, `ask_side_perc_7_day`, `bid_side_perc_7_day`, `vol_pctile_15d`, `floor_volume`, `multileg_volume` — [DATA_PROVIDER_AUDIT.md](/home/user/georgeredo/DATA_PROVIDER_AUDIT.md) [REPO]; "Volume > OI" filter is defined as "days in a row where volume transacted was greater than open interest" — [UW Substack, filters](https://unusualwhales.substack.com/p/understanding-filters-on-unusual) [VENDOR]
- NOPE (Francus): "sum of all call delta traded starting at 9:30 AM EST, minus the sum of all put delta traded, divided by the equity volume on the day"; must be recomputed as spot moves; the author's backtest used static levels (long at −60, exit −30; short at +30, exit +15) on 5-minute samples Feb–Nov 2020 (~200 days) and reports no return, win-rate or Sharpe figures; the author's own caveats: the formula cannot distinguish buy/sell-to-open from to-close, both legs of a spread add to delta, thresholds are regime-dependent, it "works best in highly liquid markets like index futures" — [critique quoting Francus](https://thisismy.substack.com/p/the-nope-brain-worm) [VENDOR]
- SpotGamma HIRO: "measures and aggregates the delta notional value from every option trade, estimating the hedging requirement associated with each transaction"; sign = estimated dealer hedging pressure; "All Trades" view "does use SpotGamma proprietary logic to filter out some trades that we consider hedged"; a "Next Expiry" toggle isolates 0DTE/next-expiry flow; guidance says next-expiry-dominated flow is "prone to reversal" and users should "wait for flows to 'shut off' and look for reversals"; no backtest statistics in the guide — [SpotGamma HIRO User Guide (PDF)](https://spotgamma.com/wp-content/uploads/2025/10/SpotGamma-HIRO-User-Guide-2.pdf) [VENDOR]
- SqueezeMetrics DIX: dollar-weighted dark-pool short-volume share across S&P 500 components since 2011 from FINRA Reg SHO daily files; thesis "short volume is actually representative of investor buying volume"; claims higher short volume correlates with higher intraday returns once above ~35%, and that readings ≥45% are "very high"; it is a daily, not intraday, series — [SqueezeMetrics, "Short is Long" (2018)](https://squeezemetrics.com/monitor/download/pdf/short_is_long.pdf) [VENDOR]
- Academic constructions: Pan–Poteshman's signal is the put/(put+call) ratio of open-buy volume (buyer-initiated, position-opening) from CBOE data carrying OCC origin codes (public customer / firm proprietary / market maker) — [Pan & Poteshman, NBER w10925 (PDF)](https://nber.org/system/files/working_papers/w10925/w10925.pdf) [PR, RFS 2006]; Hu decomposes stock order imbalance into an option-induced (delta-hedging) part and an option-independent part — [Hu 2014, JFE](https://ideas.repec.org/a/eee/jfinec/v111y2014i3p625-645.html) [PR]; Holowczak–Hu–Wu aggregate QQQQ option order flow with delta weights (price information) and vega weights (volatility information) — [Holowczak, Hu & Wu (SMU)](https://ink.library.smu.edu.sg/lkcsb_research/5215) [WP/PR, J. Derivatives 2014]; Muravyev separates option order imbalance into inventory-risk and asymmetric-information components — [Muravyev 2016, JF](https://ideas.repec.org/r/bla/jfinan/v71y2016i2p673-708.html) [PR]

### Inferences
- UW net premium, NOPE and HIRO are the same object at different weightings (premium, delta, filtered delta); differences in claimed behaviour come from the weighting and from undocumented filters, not from different information.
- Because UW excludes midpoint trades, and retail orders are routed to price-improvement auctions that frequently execute inside the spread, UW's "net premium" is systematically biased away from retail flow and toward trades that cross the spread (institutional, algorithmic, or market-maker-to-market-maker).

### Gaps
- UW does not publish the rule mapping a print's price vs NBBO to ask/bid/mid/no-side, nor the data source of `darkpool/{t}`; both must be inferred from the live `option-trades` fields (`bid_side`, `ask_side`, `mid`) and from `market_center`/`sale_cond_codes`.

## KQ1. Does signed option order flow predict the underlying's next 15–60-minute return in index ETFs, at what magnitude, and does it survive spreads?

### Takeaway
There is no peer-reviewed study showing that ask-minus-bid option premium predicts 15–60-minute SPY/QQQ/IWM returns. The best-identified intraday results on index products come from a different channel: dealer gamma/hedging demand (Baltussen et al.; Adams et al.; Ni et al.), with coefficients on the order of 5–7 bp of last-half-hour return per 1% of rest-of-day return when dealers are short gamma. The informational channel that works for single stocks (Pan–Poteshman, Hu) was explicitly tested on index options by Pan–Poteshman and found nothing.

### Cited Findings
- Pan & Poteshman (CBOE open-buy volumes, 1990–2001): low open-buy put-call-ratio stocks beat high-ratio stocks by "over 40 basis points per day and 1 percent per week on a risk-adjusted basis", decaying over several weeks; but for OEX/SPX/NDX index options "the results ... do not provide any evidence of informed trading in the index option market", and the only significant index coefficient is contrarian (discount/other-broker customers' NDX volume positively predicts next-day NDX) — [Pan & Poteshman, NBER w10925 (PDF)](https://nber.org/system/files/working_papers/w10925/w10925.pdf) [PR, single stocks; pre-2022]
- Pan & Poteshman Table 8: next-day risk-adjusted return per unit of put-call ratio is −52.6 bp (t = −32.9) for open-buy volume, +20.0 (t = 12.4) for open-sell, −0.9 (t = −0.46, nil) for close-buy, +27.4 (t = 14.6) for close-sell: the sign of information depends on whether volume opens or closes positions, which OPRA-based signals cannot see — [same source](https://nber.org/system/files/working_papers/w10925/w10925.pdf) [PR]
- Hu (JFE 2014): the option-induced component of stock order imbalance "predicts the cross-section of future stock returns" after controlling for past stock and option returns; the option-independent component "has only a transitory price impact" — [Hu 2014 abstract](https://ideas.repec.org/a/eee/jfinec/v111y2014i3p625-645.html) [PR, single stocks, daily; sample and effect sizes not in abstract]
- Holowczak, Hu & Wu (QQQQ options): aggregate option order flow shows "significantly positive correlations" with realized returns; "delta buy pressure positively predicts the underlying return"; horizon and magnitudes not in the abstract — [SMU abstract](https://ink.library.smu.edu.sg/lkcsb_research/5215) [WP 2011 / PR 2014, index ETF; pre-2022]
- Kang, Kang & Lee (J. Futures Markets 2022): "option order imbalances in the first 10 min of trading significantly predict the returns of stock index and index futures for the remainder of the day"; "simple market timing strategies result in significant profits even after transaction costs"; driven by institutional traders, not day traders; intraday momentum itself insignificant — [IDEAS abstract](https://ideas.repec.org/a/wly/jfutmk/v42y2022i3p338-364.html) [PR]; the KAIST dissertation chapter indicates KOSPI 200 — [KAIST record](https://koasas.kaist.ac.kr/handle/10203/294444)
- Muravyev, Pearson & Broussard (JFE 2013): using tick quotes for 39 liquid US stocks, "option price quotes do not contain economically significant information about future stock prices"; when put-call-parity-implied and actual stock prices disagree, option quotes adjust, not stock quotes — [summary](https://academicnewsletter.sufe.edu.cn/info/356710); [IDEAS](https://ideas.repec.org/r/eee/jfinec/v107y2013i2p259-283.html) [PR, single stocks]
- Easley, O'Hara & Srinivas (JF 1998): signed option volumes ("positive-news" and "negative-news" volume) contain information about future stock prices while unsigned volume does not; 50 firms, 44 trading days in 1990 — [CFA Digest summary](https://rpc.cfainstitute.org/research/cfa-digest/1998/11/option-volume-and-stock-prices-evidence-on-where-informed-traders-trade-digest-summary) [PR, single stocks]
- Bryzgalova, Pavlova & Sikorskaya (JF 2023; Nov 2019–Jun 2021, ETF and equity options, index options excluded): "retail trading in options, in particular, high volume imbalances in calls and puts, tends to predict returns on the underlying stocks over the next trading day", which the authors attribute to "price pressure caused by the hedging demand of the intermediaries servicing retail order flow" rather than information — [LBS open-access PDF](https://lbsresearch.london.edu/id/eprint/2827/1/The%20Journal%20of%20Finance%20-%202023%20-%20BRYZGALOVA%20-%20Retail%20Trading%20in%20Options%20and%20the%20Rise%20of%20the%20Big%20Three%20Wholesalers.pdf) [PR]
- Baltussen, Da, Lammers & Martens (JFE 2021): pooled equity-index futures 1974–2020, last-half-hour return on rest-of-day return β = 4.18 (×100, t = 7.29), R² 2.45%, out-of-sample R² 2.88% for the combined model; S&P 500 futures conditional on net gamma exposure (NGE, Jan 1996–May 2020): β = 6.63 (t = 4.78, R² 3.58%) on negative-NGE days vs 0.82 (t = 1.03, R² 0.05%) on positive-NGE days; η(rROD) timing strategy on equity-index futures: 6.86% annualized, Sharpe 1.73, success rate 55% — [Baltussen et al. (PDF)](https://academicweb.nd.edu/~zda/intramom.pdf) [PR]
- Baltussen et al. NGE proxy assumes dealers are short all puts and long all calls on OptionMetrics open interest, extended with SqueezeMetrics data; 2,930 negative-NGE vs 3,158 positive-NGE days — [same source](https://academicweb.nd.edu/~zda/intramom.pdf) [PR]
- Gao, Han, Li & Zhou (JFE 2018): SPY 1993–2013, first half-hour return predicts last half-hour return; R² around 2% (0.018 out-of-sample in the working-paper version); stronger on volatile, high-volume and macro-news days — [summary](https://academicnewsletter.sufe.edu.cn/info/356150); [CXO summary](https://cxoadvisory.com/calendar-effects/first-and-last-half-hours-of-trading-linked) [PR]
- Adams et al. (SSRN 5641974, summarized Feb 2026): S&P 500 realized volatility about 60 annualized bp lower on 0DTE days (Tue/Thu identification before May 2022); "higher net gamma predicts lower S&P 500 volatility over the next 10 minutes, with the effect fading after about an hour", predicts reversals in E-mini order flow and "negative momentum in high-frequency returns"; hedging a positive-gamma book "can be profitable on average when transaction costs are low" — [Quantpedia summary](https://quantpedia.com/do-sp500-0dtes-options-increase-market-volatility/) [WP, post-2022 index]
- Ni, Pearson, Poteshman & White (working paper; later RFS): CBOE open interest by trader type 1990–2001; a one-standard-deviation shock to likely-hedgers' net gamma is associated with a 37 bp change in daily absolute return against a 310 bp average (~12%); low vs high market-maker net-gamma decile differ by 100 bp in average absolute return — [OU working paper (PDF)](https://ou.edu/dam/price/Finance/CFS/paper/pdf/pearsonPoteshmanWhite.pdf) [WP/PR, single stocks]
- Barbon & Buraschi ("Gamma Fragility"): intraday momentum (reversal) is explained by negative (positive) ex-ante dealer gamma imbalance interacted with illiquidity; flash crashes more likely and larger on negative-gamma days — [paper page](https://abarbon.com/papers/gamma-fragility) [WP]
- Cboe (Xu, Sept 2023): SPX 0DTE flow "remarkably balanced"; on 15 Aug 2023 the 4440 put traded >100k contracts and market makers ended ~3k contracts short (~3% of gross); market-maker net gamma ranged ~$170mm–$670mm through the day, i.e., 0.04–0.17% of ~$400bn daily S&P futures liquidity; no uptick in 2-sigma one-minute gap moves — [Cboe Insights](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options) [EXCH]
- Cboe (Xu, May 2025): retail ≈ 50–60% of SPX 0DTE volume; >95% of 0DTE trades are limited-risk (outright longs or spreads), ~4% naked short; net market-maker gamma hedging "de minimis", at most ~0.2% of SPX daily liquidity; customer activity "extremely balanced" — [Cboe Insights](https://www.cboe.com/insights/posts/0-dt-es-decoded-positioning-trends-and-market-impact) [EXCH]; a summary of the same report adds that "just over half of opening customer trades are outright puts or calls", the rest multi-leg, and that the SPX 0DTE put/call ratio "consistently hovered around one" — [Harbourfront summary](https://harbourfrontquant.substack.com/p/risk-timing-and-strategy-key-differences)
- Muravyev & Pearson (RFS 2020): traders who time executions pay effective spreads "less than 40%" of conventional measures; sample of 37 stocks and 2 ETFs 2003–2006 shows timed trades at ~1.3c effective vs 8.1c quoted — [IDEAS](https://ideas.repec.org/a/oup/rfinst/v33y2020i11p4973-5014..html); [CXO summary](https://www.cxoadvisory.com/equity-options/timing-option-trades-to-suppress-trading-frictions/) [PR]
- Garleanu, Pedersen & Poteshman (RFS 2009): end users are net long index options, especially OTM puts; demand pressure raises option prices in proportion to unhedgeable risk — [NBER w11843](https://www.nber.org/papers/w11843) [PR, daily]

### Inferences
- The single-stock informational results (40 bp/day) come from opening-buy volume with trader-type codes and die at the index level even in the richest dataset; a raw ask-minus-bid premium series on SPY should be expected a priori to carry a fraction of that, and the index test in Pan–Poteshman says the informational fraction is ~zero.
- The one index-level intraday result that is robust and replicated (Baltussen; Gao; Adams) is mechanical hedging: direction of the day's move → last-30-minute continuation when dealers are short gamma, reversal/vol damping when long gamma. That is a positioning signal (open interest × gamma), not a flow signal, but UW flow can be used to update it intraday.
- Kang et al. is the only paper that uses early-session option order imbalance to predict the rest of the session on an index and reports post-cost profits; it is Korean (KOSPI 200), where options are ~retail-dominated and structurally different. Treat it as a hypothesis to test on SPY, not as evidence.
- Bryzgalova's next-day predictability from retail call/put imbalances is a hedging-pressure effect; on index ETFs with balanced flows (Cboe) the net pressure is small, so the effect is likely weaker on SPY than on the single names driving her result.

### Gaps
- No peer-reviewed or exchange study of 15–60-minute predictability from signed option premium/volume on SPY/QQQ/IWM was found; the closest (Holowczak–Hu–Wu on QQQQ) does not report horizon or magnitudes in accessible text and is pre-2022.
- Hu (2014) sample period, signing rule, horizon and bp magnitudes are behind a paywall (abstract only).
- Kang, Kang & Lee effect sizes (R², profits) and the exact market are not in the abstract.
- Adams et al. (SSRN 5641974) was accessible only via Quantpedia's summary; Dim–Eraker–Vilkov only via a seminar abstract.

## KQ2. Is there evidence that sweep-tagged or "unusual" prints predict option returns (not just stock returns) intraday?

### Takeaway
No academic study of option sweeps was found. What exists says (a) in equities, ISOs are informed; (b) aggregate option order imbalance predicts next-day option returns through dealer inventory (Muravyev: ~1% per SD), which is a reason to fade aggressive buying in the option itself, not follow it; (c) publicly-flagged "unusual activity" shows no abnormal returns (Jiang & Strong); (d) 0DTE long-premium retail trades lose ~50–60% on average with ~60% of losses being transaction costs.

### Cited Findings
- Chakravarty, Jain, Upson & Wood (JFQA 2012): in US equities ISOs are 46% of trades and 41% of volume, carry a "significantly larger information share" than non-ISO trades, and post-trade returns suggest "informed institutions are the main users" — [SSRN abstract](https://papers.ssrn.com/abstract=1460865) [PR, equities not options]
- Jiang & Strong (CNBC "Unusual Option Activity" segment, Jan 2014–Dec 2018): featured trades predict returns before coverage and "prices reverse significantly after the coverage"; across a broad sample of unusual option activity they find no comparable abnormal returns, concluding the featured trades "are not very unusual" — [Institutional Investor summary](https://www.institutionalinvestor.com/article/2bsx1291ksdkihtqnf6yo/portfolio/is-it-worth-following-the-smart-money) [WP, single stocks]
- Muravyev (JF 2016): both inventory and information components of option price impact are "large", inventory larger; "Past order imbalances have greater predictive power than any other commonly used predictor of option returns"; working-paper abstract: "One standard deviation increase in the inventory-related order imbalance corresponds to 1% higher expected option returns on the next day"; expiration-week rollover "leads to a 5.7% drop in prices for non-expiring options" — [JF listing](https://ideas.repec.org/r/bla/jfinan/v71y2016i2p673-708.html); [working-paper abstract](https://academicnewsletter.sufe.edu.cn/info/359812); [HSE seminar abstract](https://icef.hse.ru/news/44378303.html) [PR, single stocks, daily]
- Fahlenbrach & Sandås (JBF 2010, FTSE-100 index options): strategy trades are ~37% of trades and >75% of volume; order flow in directional strategies shows "no evidence of information about future returns"; volatility-sensitive strategies show some volatility information; some strategy users "appear to follow unprofitable trend chasing strategies" — [IDEAS abstract](https://ideas.repec.org/a/eee/jbfina/v34y2010i10p2370-2385.html) [PR, index, pre-2022]
- Beckmeyer, Branger & Gayda (SSRN 4404704; CBOE SPX trades with trader-type codes, Jan 2021–Feb 2023): retail long 0DTE positions lost on average 53% (full sample) and 61% (since May 2022); retail short positions gained 48% / 56%; retail effective spreads 6.1% (calls) / 4.9% (puts) vs 13.1% / 10.1% non-retail; aggregate retail losses > $70m, $184k/day full sample and $358k/day since 16 May 2022; ~60% of daily losses from transaction costs and ~60% from puts; retail buys more than it sells, leaving market makers net short — [WealthManagement write-up](https://www.wealthmanagement.com/equities/retail-investors-are-in-love-with-same-day-options); [Neudata review](https://neudata.co/literature-reviews/zero-day-to-expiry-options-a-losing-bet-for-retail-traders) [WP, post-2022 index; primary SSRN page not retrievable here]
- Vilkov ("0DTE Trading Rules", SPX 0DTE Sept 2016–Jan 2024): static rules opened at 10:00 (also 13:00, 15:00) and held to expiry; strong variance risk premium; "median returns for popular options strategies are mostly negative" except risk reversal; realized P&L largely explained by realized skewness; "Static rules are reported to fail, while conditional rules that adapt to volatility or skew might ... extract edge" — [CXO summary](https://cxoadvisory.com/equity-options/0dte-strategy-outcomes); [Hull Tactical note](https://hulltactical.com/2026/07/08/0dte-options-tiny-edge-huge-distribution/) [WP]
- Bryzgalova et al.: retail prefers weekly options with average quoted bid-ask spread 12.6% (29% for the shortest-dated), and aggregate retail losses were ~$2.1bn Nov 2019–Jun 2021; "those who buy short-term options ... lose money, and those who sell these contracts ... make significant profits, even after transaction costs" — [LBS PDF](https://lbsresearch.london.edu/id/eprint/2827/1/The%20Journal%20of%20Finance%20-%202023%20-%20BRYZGALOVA%20-%20Retail%20Trading%20in%20Options%20and%20the%20Rise%20of%20the%20Big%20Three%20Wholesalers.pdf) [PR]
- UW's sweep definition is operational ("market order ... sweeps different exchanges") and its alert post makes no accuracy or win-rate claims — [UW Substack](https://unusualwhales.substack.com/p/a-breakdown-of-every-type-of-flow) [VENDOR]; a third-party explainer notes a sweep marks "urgency, not intent" and can be a hedge or one leg of a spread — [LuxAlgo](https://www.luxalgo.com/blog/unusualwhales-scanner-sweeps-flow-and-edge/) [VENDOR]

### Inferences
- For the option leg, the documented short-horizon effect of aggressive flow is adverse to a follower: dealer inventory pushes the option's price up on the day of buying pressure and it reverts (Muravyev), and expiring-week rollover is a further negative drift. A "follow the sweep" rule in SPY 0DTE buys at the post-pressure price and pays theta; Beckmeyer's −53%/−61% on long retail 0DTE positions is the realized outcome of exactly this.
- The only "unusual flow" result with a positive sign (pre-CNBC drift in Jiang & Strong) is in single stocks and disappears for broadly-defined unusual activity.

### Gaps
- No study of OPRA sweep/ISO-flagged option prints and subsequent option or stock returns was found (US or elsewhere).
- Muravyev's data source, sample period and the exact horizon/decay of the 1% effect could not be verified beyond abstracts.
- No vendor (UW, SpotGamma, Cheddar Flow) publishes an out-of-sample hit-rate or return for sweep or unusual-activity alerts; none was found in their public material.

## KQ3. What is known about dark-pool buy/sell imbalance as a short-horizon predictor, and about NBBO-based side tagging of off-exchange prints?

### Takeaway
Dark prints are on average less informed than lit prints and have the lowest price impact; signed dark imbalance has documented intraday (15–120 min) predictive power only in illiquid single stocks. The TRF feed behind "dark pool" endpoints is ~83% wholesaler internalization and ~17% ATS, and NBBO-based signing of those prints is unreliable unless done against the midpoint (28% mis-signed with the sub-penny rule vs ~5% with midpoint signing). For SPY/QQQ/IWM there is no evidence of a usable intraday dark-imbalance signal.

### Cited Findings
- Zhu (RFS 2014, theory): informed traders cluster on one side and face higher execution risk in dark pools, so dark pools draw uninformed flow and can improve exchange price discovery while reducing exchange liquidity — [Zhu, RFS (PDF)](https://www.mit.edu/~zhuh/Zhu_darkpool_RFS.pdf) [PR]
- Comerton-Forde & Putniņš (JFE 2015, ASX): "orders executed in the dark tend to be less informed than orders executed in the lit market"; informational efficiency deteriorates "when dark trading in a given stock exceeds approximately 10% of dollar volume"; block trades away from the lit market are benign up to ~40% of dollar volume; Australian dark pools "can only trade at the midpoint or on the same price grid" unlike the US — [accepted manuscript (PDF)](https://opus.lib.uts.edu.au/bitstream/10453/121967/1/manuscript.pdf) [PR, Australia]
- Nimalendran & Ray (JFM 2014, proprietary US dark-pool data): in less liquid stocks, dark trades coincide with wider spreads and price impact on lit venues and "signed trades ... have predictive power for returns over the following 15 to 120 minutes"; trades in liquid stocks and negotiated blocks "pass less information to lit venues" — [IDEAS abstract](https://ideas.repec.org/a/eee/finmar/v17y2014icp230-261.html) [PR, single stocks]
- Bershova, Stephens & Waelbroeck (J. Investment Strategies): executions against hidden/dark liquidity move returns least among displayed-quote executions, dark executions and net limit-order flow — [IDEAS](https://ideas.repec.org/a/rsk/journ6/2426601.html) [PR]
- Buti, Rindi & Werner (as cited by Comerton-Forde & Putniņš): data from 11 of 32 US dark pools; dark pools "improve spreads, depth, and short-term volatility" — [CF&P manuscript](https://opus.lib.uts.edu.au/bitstream/10453/121967/1/manuscript.pdf) [WP 2011 / PR]
- Composition of off-exchange prints: Cboe reports TRF share rose to 47% of total consolidated volume in 2024, of which 17.0% executed on ATSs and 83.0% through principal dealers (wholesalers) — [Cboe, 2024 year in review](https://www.cboe.com/insights/posts/north-american-equities-year-in-review) [EXCH]; Nasdaq notes off-exchange exceeded 50% in Nov 2024 — [Nasdaq](https://www.nasdaq.com/articles/exchange-trading-increases-across-all-types-stocks) [EXCH]; Rosenblatt tracks ATS dark pools at ~13.5–17% of US volume — [Rosenblatt](https://www.rblt.com/market-structure-reports/let-there-be-light-us-edition-55) [VENDOR]
- Boehmer, Jones, Zhang & Zhang (JF 2021): sub-penny TRF prints identify marketable retail orders; stocks with net retail buying outperform by ~10 bp over the following week — [IBKR/Alpha Architect summary](https://www.interactivebrokers.com/campus/ibkr-quant-news/how-to-track-retail-investor-activity-in-taq/) [PR, weekly horizon]
- Barber, Huang, Jorion, Odean & Schwarz (JF 2024): placing 85,000 real retail trades, the sub-penny algorithm flags ~35% as retail, "incorrectly signs 28% of identified trades", and yields uninformative imbalances for 30% of stocks; signing against the quote midpoint instead "reduces the signing error rates to 5%" — [SSRN abstract](https://papers.ssrn.com/abstract=4202874) [PR]
- Battalio, Jennings, Saglam & Wu (proprietary wholesaler data): the sub-penny method identifies less than one-third of retail trades and "a large number of institutional trades print on the TRF at non-quote-midpoint sub-penny prices" — [LSU conference PDF](https://tc.lsu.edu/business/files/event-files/2025-finance-mardi-gras/battalio-jennings-saglam-wu.pdf) [WP]
- Barber/Odean ("Resolving a paradox"): retail order imbalance positively predicts short-horizon returns, yet long-short strategies on it earn poor returns among heavily retail-traded stocks — [Haas working paper (PDF)](https://faculty.haas.berkeley.edu/odean/Papers%20current%20versions/resolving_a_paradox_retail_trades_positively_predict_returns_but_are_not_profitable.pdf) [WP]
- Chordia et al.: no evidence that daily aggregate order imbalances predict next-day stock-market returns, though large negative-imbalance/negative-return days see reversals — [Chordia et al. (PDF)](https://www.cis.upenn.edu/~mkearns/finread/Chordia_buy-sell_orders.pdf) [PR]
- Short-volume proxies: Diether, Lee & Werner find increased short sales predict negative returns but a daily trading strategy's costs "wipe out any profits" — [Diether, Lee & Werner (PDF)](https://www.cis.upenn.edu/~mkearns/finread/short_sellers_predict_returns.pdf) [PR, single stocks]; an HKUST thesis (2010–2018) finds the FINRA daily short-volume ratio predicts negative returns with decay up to a year — [HKUST thesis](https://lbezone.hkust.edu.hk/rse/?p=51474) [thesis]
- SqueezeMetrics' own paper says of DIX: "on a 1-day timeframe, you don't see much", with a visible slope only at 60-day horizons; the intraday claim is a contemporaneous correlation between a day's short-volume share and that day's return — [SqueezeMetrics "Short is Long"](https://squeezemetrics.com/monitor/download/pdf/short_is_long.pdf) [VENDOR]

### Inferences
- A UW `darkpool/{t}` feed for SPY is dominated by wholesaler internalization of retail marketable orders, not institutional dark-pool crosses. Signing those prints against `nbbo_bid/nbbo_ask` recovers retail direction with ~5% error if done against the midpoint (BHJOS), but retail SPY imbalance is the flow that Bryzgalova/Cboe describe as balanced and hedged; any predictive content is at the weekly horizon (BJZZ, ~10 bp/week) and not profitable after costs (Odean).
- Prints exactly at the midpoint (true ATS crosses) cannot be signed by NBBO at all; the repo's own prefetch script already counts `at_mid` and `no_nbbo` rows, so the first diagnostic is the share of SPY prints that are signable.
- Large block prints reported with delay or with special `sale_cond_codes` should be excluded from any minute-level test (CF&P: blocks are benign/uninformed).

### Gaps
- No published figure for the share of US ATS volume executed at the midpoint was found (FINRA ATS transparency data would be needed).
- No study tests intraday dark/TRF imbalance on index ETFs specifically.
- UW does not document whether `darkpool/{t}` includes all TRF prints or only ATS-tagged ones; `market_center` values must be mapped empirically.

## KQ4. How do practitioners define a per-strike "burst", and is there any out-of-sample evidence for it?

### Takeaway
Practitioner "bursts" are rule-based clusters (same contract, sub-second to ~1,000-second windows, trade-count and premium thresholds scaled by market cap, often with a volume-vs-OI condition). No vendor or academic source reports out-of-sample returns for such alerts; the closest academic analog (opening vs closing volume) shows that bursts without open/close information mix signals of opposite sign.

### Cited Findings

### Inferences
- A defensible burst definition for SPY must be relative (z-score of a strike's 1-minute ask-side premium against its own trailing intraday baseline and against the strike's share of total chain premium), because absolute premium thresholds designed for single names are hit continuously on SPY.
- Without OPRA trade-type and open/close information, a "burst" at a strike pools: opening retail buys (informative only via hedging pressure), closing trades (sign-flipped), spread legs (hedged), and market-maker-to-market-maker auctions. The expected net sign is close to zero on an index ETF.

### Gaps
- No published out-of-sample test of any per-strike burst rule (vendor or academic) was found.
- "Sus strikes" is a Slayer/GeorgeFi term; no external definition exists.

## KQ5. Why do most retail "flow alert" strategies fail?

### Takeaway
Five mechanical reasons, each with evidence: side mis-attribution (13–20% error even with proprietary data, worse for complex trades), hedging/dealer-inventory flow dominating the tape, multi-leg legs appearing as outright trades, inability to separate market-maker from customer initiation without OCC codes, and selection bias in what gets alerted or publicized — on top of 0DTE spreads and theta that consume ~60% of retail losses.

### Cited Findings
- Savickas & Wilson (JFQA 2003, CBOE data with true direction): quote rule signs 83% of classifiable trades correctly, Lee–Ready 80%, EMO 77%, tick 59%; "outside-quote and reversed-quote trades are highly misclassified by all four rules"; index complex trades not routed via RAES (~15% of sample) are misclassified about half the time — [IDEAS abstract](https://ideas.repec.org/a/cup/jfinqa/v38y2003i04p881-902_00.html) [PR, pre-2022]
- Grauer, Schuster & Uhrig-Homburg, "Option Trade Classification" (SSRN 4098475, 2023) exists and is implemented in the `tclf` package, but I could not retrieve its accuracy figures — [SSRN DOI](https://doi.org/10.2139/ssrn.4098475); [tclf on PyPI](https://pypi.org/project/tclf) [WP, unverified]
- UW itself: ask-side ≠ buy, bid-side ≠ sell; mid trades excluded; closing trades misread as new bias — [UW Substack](https://unusualwhales.substack.com/p/how-to-use-the-net-premium-tool-on) [VENDOR]
- Hedging flow: Hu's option-independent stock imbalance has "only a transitory price impact" — [Hu 2014](https://ideas.repec.org/a/eee/jfinec/v111y2014i3p625-645.html) [PR]; Bryzgalova attributes next-day predictability from retail option imbalance to intermediaries' hedging demand — [LBS PDF](https://lbsresearch.london.edu/id/eprint/2827/1/The%20Journal%20of%20Finance%20-%202023%20-%20BRYZGALOVA%20-%20Retail%20Trading%20in%20Options%20and%20the%20Rise%20of%20the%20Big%20Three%20Wholesalers.pdf) [PR]; Cboe finds SPX 0DTE customer flow "extremely balanced" with net gamma hedging ≤0.2% of liquidity — [Cboe 2025](https://www.cboe.com/insights/posts/0-dt-es-decoded-positioning-trends-and-market-impact) [EXCH]; JPMorgan research cited by Risk.net puts the 0DTE net selling imbalance at ~2% of ~$500bn notional — [Risk.net/Numerix](https://www.risk.net/insight/markets/7959202/zero-day-options-unique-market-dynamics-and-risk-considerations) [VENDOR]
- Multi-leg: strategy trades are >75% of FTSE-100 index option volume and directional strategy flow has no return information — [Fahlenbrach & Sandås](https://ideas.repec.org/a/eee/jbfina/v34y2010i10p2370-2385.html) [PR]; just under half of opening SPX 0DTE customer trades are multi-leg — [Harbourfront summary of Cboe 2025](https://harbourfrontquant.substack.com/p/risk-timing-and-strategy-key-differences) [EXCH via summary]; a 2015 industry piece put complex order books near 40% of US options volume — [FlexTrade](https://flextrade.com/?p=3450) [VENDOR, dated]
- Market maker vs customer: the OCC assigns origin codes (public customer / firm proprietary / market maker) that CBOE's dataset carries and that Pan–Poteshman, Ni et al. and Beckmeyer et al. rely on — [NBER w10925 (PDF)](https://nber.org/system/files/working_papers/w10925/w10925.pdf); [OU working paper (PDF)](https://ou.edu/dam/price/Finance/CFS/paper/pdf/pearsonPoteshmanWhite.pdf); [WealthManagement on Beckmeyer et al.](https://www.wealthmanagement.com/equities/retail-investors-are-in-love-with-same-day-options) [PR/WP]; OPRA-based vendors have only trade-type/auction flags — [Bryzgalova, LBS PDF](https://lbsresearch.london.edu/id/eprint/2827/1/The%20Journal%20of%20Finance%20-%202023%20-%20BRYZGALOVA%20-%20Retail%20Trading%20in%20Options%20and%20the%20Rise%20of%20the%20Big%20Three%20Wholesalers.pdf)
- Selection/publicity bias: CNBC-featured unusual trades reverse after coverage; unfeatured unusual activity shows no abnormal return — [Institutional Investor on Jiang & Strong](https://www.institutionalinvestor.com/article/2bsx1291ksdkihtqnf6yo/portfolio/is-it-worth-following-the-smart-money) [WP]
- Execution timing: liquidity takers who time orders pay <40% of conventional effective spreads, implying the aggressive prints a follower copies were placed when quotes were about to move — [Muravyev & Pearson 2020](https://ideas.repec.org/a/oup/rfinst/v33y2020i11p4973-5014..html) [PR]
- Costs: ~60% of retail 0DTE daily losses are transaction costs; retail effective spreads 4.9–6.1% — [WealthManagement on Beckmeyer et al.](https://www.wealthmanagement.com/equities/retail-investors-are-in-love-with-same-day-options) [WP]; retail weekly options carry 12.6% average quoted spreads — [Bryzgalova, LBS PDF](https://lbsresearch.london.edu/id/eprint/2827/1/The%20Journal%20of%20Finance%20-%202023%20-%20BRYZGALOVA%20-%20Retail%20Trading%20in%20Options%20and%20the%20Rise%20of%20the%20Big%20Three%20Wholesalers.pdf) [PR]

### Inferences
- With ~15–20% side error and roughly half of volume in spreads, the signal-to-noise of raw ask-minus-bid premium on an index chain is low even before hedging neutralization; the informative subset (opening single-leg customer buys) is unobservable in OPRA.

### Gaps
- Modern (post-2015, multi-exchange, price-improvement-auction) option trade-classification accuracy is not verified here (Grauer et al. would be the source).
- No vendor publishes its side-assignment rule or alert hit-rates.

## KQ6. Which signal constructions have the best chance on index ETFs, where most volume is hedging and 0DTE?

### Takeaway
On SPY/QQQ/IWM the evidence favors (1) positioning-conditioned continuation/reversal (dealer net gamma × rest-of-day return, especially the last 30–60 minutes), (2) delta-weighted, hedging-filtered flow (HIRO/NOPE-type) used as an input to update that positioning intraday, (3) early-session (first 10–30 min) opening-flow imbalance as in Kang et al., and (4) contrarian use of extreme next-expiry/retail premium bursts and inventory effects in the options themselves. Raw directional "follow the premium" has no support.

### Cited Findings
- Negative-NGE days: last-30-min β on rest-of-day return 6.63 vs 0.82 on positive-NGE days; NGE × rROD interaction −123 (t = −3.42) — [Baltussen et al. (PDF)](https://academicweb.nd.edu/~zda/intramom.pdf) [PR]
- Higher dealer net gamma on 0DTE days predicts lower 10-minute volatility, order-flow reversals and negative HF momentum, fading within ~1 hour — [Quantpedia on Adams et al.](https://quantpedia.com/do-sp500-0dtes-options-increase-market-volatility/) [WP]
- Dealer net gamma explains ~12% of daily absolute return variation and a 100 bp decile spread in absolute returns (single stocks) — [NPPW (PDF)](https://ou.edu/dam/price/Finance/CFS/paper/pdf/pearsonPoteshmanWhite.pdf) [WP/PR]
- Delta- and vega-weighted aggregation across contracts is what makes option order flow predictive for QQQQ — [Holowczak, Hu & Wu](https://ink.library.smu.edu.sg/lkcsb_research/5215) [WP/PR]
- First-10-minute option order imbalance predicts the rest-of-day index return with post-cost profits (institutional-driven) — [Kang, Kang & Lee](https://ideas.repec.org/a/wly/jfutmk/v42y2022i3p338-364.html) [PR, Korea]
- Index put-call ratios work, if at all, as contrarian signals; index options show no informed-trading predictability — [Pan & Poteshman (PDF)](https://nber.org/system/files/working_papers/w10925/w10925.pdf) [PR]
- Vendor guidance already treats next-expiry (0DTE) flow as reversal-prone and advises waiting for flows to "shut off" — [HIRO guide (PDF)](https://spotgamma.com/wp-content/uploads/2025/10/SpotGamma-HIRO-User-Guide-2.pdf) [VENDOR]; NOPE's design is mean-reversion at extremes — [NOPE critique](https://thisismy.substack.com/p/the-nope-brain-worm) [VENDOR]
- Option-level inventory effect: ~1% next-day option return per SD of inventory-related imbalance; expiration rollover selling pressure — [Muravyev working-paper abstract](https://academicnewsletter.sufe.edu.cn/info/359812) [PR]
- SPX 0DTE flow: ~50–60% retail, >95% limited-risk structures, P/C ≈ 1, net hedging ≤0.2% of liquidity — [Cboe 2025](https://www.cboe.com/insights/posts/0-dt-es-decoded-positioning-trends-and-market-impact) [EXCH]; 0DTE 56–62% of SPX volume in 2025 — [Cboe Aug 2025](https://www.cboe.com/insights/posts/spx-0-dte-options-jump-to-record-62-share-in-august) [EXCH]

### Inferences
- The highest-prior construction for Slayer is: estimate intraday dealer net gamma for SPY/QQQ/IWM (UW `gex`/`gex_strike` or own computation from OI × gamma), update it with signed 0DTE flow from `flow-per-strike-intraday` (sign flipped to the dealer side), and condition a rest-of-day → last-hour continuation/reversal rule on its sign and magnitude. This is the only family with replicated, index-level, intraday evidence.
- The second is an opening-window (9:30–9:40/10:00) net delta-weighted imbalance from `net-prem-ticks`/`flow-per-strike-intraday` predicting the 10:00–16:00 return (Kang et al. analogue), with the rest-of-day realized at SPY share level where costs are negligible.
- A third, for the options leg specifically, is the contrarian/inventory play: fade abnormal ask-side premium bursts in a single 0DTE strike by selling (or not buying) that strike, using `option-contract/{id}/intraday` to measure the post-burst drift; this is consistent with Muravyev and Beckmeyer and with UW/SpotGamma's own reversal heuristics.

### Gaps
- No study provides intraday (minute-level) dealer gamma estimates for ETFs; Baltussen's NGE is daily and assumes dealers short all puts / long all calls.
- Kang et al. has not been replicated on US index products.

## KQ7. Which exact tests should we run on the UW endpoints, and what effect size is needed to beat a 1–2% half-spread on a ~$1 0DTE premium or a 1-cent spread on SPY shares?

### Takeaway
For SPY shares the cost hurdle is ~0.15–0.2 bp round trip, so almost any statistically real 15–60-minute effect clears it; the binding constraint is statistical power and regime stability. For a ~$1 0DTE option the hurdle is 2–4% of premium in spread plus ~4% (15 min) to ~17% (60 min) in theta for an ATM contract, which translates into a required directional move of roughly 2–3 bp (15 min) to 6–7 bp (60 min) in SPY, i.e., the same order as the strongest documented conditional effects (5–7 bp per 1% rest-of-day move in the last 30 minutes), so long-premium strategies are marginal even with a real signal.

### Cited Findings
- SPY, QQQ and IWM options quote in $0.01 increments at all price levels under the Penny Interval Program — [SEC filing, Cboe C2 Rule 6.4 exhibit](https://www.sec.gov/files/rules/sro/c2/2020/34-89081-ex5.pdf) [EXCH]
- Documented conditional effect sizes to benchmark against: last-30-min β 4.18–6.63 (×100) on rest-of-day return, R² 2.5–3.6%, OOS R² 2.9% — [Baltussen et al. (PDF)](https://academicweb.nd.edu/~zda/intramom.pdf) [PR]; SPY first-half-hour → last-half-hour R² ≈ 2% — [Gao et al. summary](https://academicnewsletter.sufe.edu.cn/info/356150) [PR]; next-day option return ≈ 1% per SD of inventory imbalance — [Muravyev abstract](https://academicnewsletter.sufe.edu.cn/info/359812) [PR]; 10-minute vol and order-flow reversal effects of net gamma fading within an hour — [Quantpedia on Adams et al.](https://quantpedia.com/do-sp500-0dtes-options-increase-market-volatility/) [WP]
- Available history: UW market tide back to 2022-09-28 — [UW docs](https://api.unusualwhales.com/docs/operations/PublicApi.MarketController.market_tide); `net-prem-ticks` 1-min, ~405 rows/day; `flow-per-strike-intraday` 1-min, 2,484 rows/day for SPY; `option-contract/{id}/intraday` 390 rows/day with historical dates; `darkpool/{t}` tick-level paged; `option-trades` live day only, history via ~1.5 GB daily full-tape zips — [DATA_PROVIDER_AUDIT.md](/home/user/georgeredo/DATA_PROVIDER_AUDIT.md) [REPO]
- Retail-print signing: midpoint-based signing error ~5% vs 28% for the sub-penny rule — [BHJOS, SSRN](https://papers.ssrn.com/abstract=4202874) [PR]

### Inferences
Cost hurdles (my calculation; assumptions stated):
- SPY shares: quoted spread $0.01 → half-spread $0.005; at SPY ≈ $500–$700 that is 0.07–0.10 bp per side, ~0.15–0.2 bp round trip, plus negligible fees. A 15-minute SPY return has σ ≈ 20–30 bp (1–1.5% daily vol × √(15/390)). Detecting a conditional mean of μ with n non-overlapping observations needs t = μ√n/σ ≥ 2: with σ = 25 bp and n ≈ 2,000 signal-triggered windows (≈ 8/day over a year), μ ≈ 1.1 bp is the minimum detectable effect — about 5–7× the cost. So on shares the test is about existence and stability, not cost.
- ~$1 0DTE SPY option: half-spread 1–2% ($0.01–0.02) → round trip 2–4% of premium. For an ATM option, price ≈ 0.4·S·σ·√T, so theta ≈ premium/(2T): with ~3 hours to expiry that is ≈ $0.17/hour (≈ 17%/hour) and ≈ 4% per 15 min. Required gross directional edge for a long: ≈ 6–8% of premium at 15 min, ≈ 20% at 60 min. With |delta| ≈ 0.5, that is a $0.12–0.16 (≈ 2–3 bp at $600) move in 15 min or ≈ $0.40 (≈ 6–7 bp) in 60 min, before gamma gains on larger moves. The strongest documented conditional effects (≈ 5–7 bp of last-30-min return per 1% rest-of-day move on short-gamma days) are of this order only on large-move days, which is why long-premium "flow following" is marginal and short-premium/contrarian constructions dominate in the literature.
- Implication: run every test twice — on SPY 1-minute shares (cost ≈ 0) to establish whether the signal exists, then on the `option-contract/{id}/intraday` mid-to-mid path with explicit half-spread and theta to see what survives.

Recommended tests (feature, horizon, benchmark, statistic):
1. Signed flow → underlying (existence test). Feature: per-minute net premium (`net-prem-ticks`: net_call_premium − net_put_premium) and net delta-weighted volume (from `flow-per-strike-intraday`, delta from strike/IV/time) cumulated over trailing 5/15/30 min, standardized by trailing 20-day same-time-of-day distribution. Target: SPY 1-minute mid-to-mid return over next 15/30/60 min, non-overlapping. Benchmark: AR(1) of past 15-min return and time-of-day dummies. Statistic: Fama–MacBeth-style daily regressions with Newey–West t on pooled; OOS R² against the time-of-day mean (as in Baltussen); decile spread of next-15-min return top vs bottom signal decile. Pass if OOS R² > 0 and decile spread > ~1 bp with t > 3 over ≥ 250 days (2022-09-28 onward, which is post-daily-expiration).
2. Gamma-conditioned intraday momentum (replication). Feature: rest-of-day return 9:30→15:30 and dealer net gamma sign/magnitude (UW gex endpoints or OI × gamma with Baltussen's dealer-sign convention, updated with intraday 0DTE flow). Target: 15:30→16:00 SPY return. Benchmark: unconditional β (expect ~4–5 ×100). Statistic: β on NGE<0 vs NGE≥0 subsamples, interaction t-stat, strategy Sharpe of η(rROD) conditional on NGE<0. Pass if the conditional β difference replicates (≈ 6 vs ≈ 1) in 2022–2026 data.
3. Opening-window imbalance (Kang analogue). Feature: delta-weighted signed option volume 9:30–9:40 and 9:30–10:00 (ask-side minus bid-side, puts sign-flipped), scaled by its 20-day distribution. Target: 10:00→16:00 SPY return. Benchmark: first-half-hour return (Gao). Statistic: β, t, R² and a long/short timing rule's after-cost Sharpe on shares. Pass if the imbalance adds to the first-half-hour return (incremental R² > 0 OOS).
4. Per-strike burst on the option itself (inventory/contrarian test). Feature: 1-minute ask-side premium at a 0DTE strike exceeding z ≥ 3 versus its own trailing 30-minute baseline and ≥ 10% of chain premium that minute (single-leg proxy: require the strike's `multi_leg_volume` share < 20% in `option-contract/{id}/intraday`). Target: that contract's mid-to-mid return over the next 5/15/30 min and the underlying's return. Benchmark: matched strikes without a burst at the same minute. Statistic: mean and median post-burst drift with bootstrap CIs; sign test. Expect negative drift net of theta if Muravyev's inventory channel dominates; a positive drift exceeding 2× half-spread + theta would be the first evidence for "follow the burst".
5. Dark/TRF print imbalance. Feature: signable SPY prints from `darkpool/{t}` signed against the NBBO midpoint (exclude exact-mid, delayed and block condition codes), imbalance over trailing 15/30 min as a share of volume. Target: next 15/30/60-min SPY return. Benchmark: lit-volume imbalance from 1-minute bars (tick rule). Statistic: as in test 1, plus the share of prints that are signable (diagnostic). Prior: zero to slightly negative (retail imbalance → hedged/reversing), with any positive effect at ≥ 1-week horizons only.
6. Market tide vs single-ticker tide. Feature: 5-minute market-wide net premium (`market-tide`) versus SPY `net-prem-ticks`. Target: SPY 15/30/60-min. Statistic: Granger-style incremental R² of market tide over SPY-own tide; horse-race decile spreads. Prior: market tide adds little once SPY's own flow is included because SPX/SPY dominate aggregate premium.
7. Side-tag quality audit (prerequisite). On live days, pull `option-trades` for SPY and compare UW's `bid_side/ask_side/mid` to a midpoint rule on the trade's own NBBO; measure the share of mid/no-side prints by time of day and the share of multi-leg-flagged volume. If > 20% of premium is unsignable or multi-leg, apply the multi-leg exclusion in tests 1 and 4.

### Gaps
- The theta and spread arithmetic above uses an ATM, 3-hours-to-expiry approximation; actual SPY 0DTE spreads by moneyness/time must be measured from `option-contract/{id}/intraday` bid/ask fields, which the repo audit flags as approximate for history.
- None of the referenced papers reports effect sizes at the 15–60-minute horizon for US index ETFs; the hurdle comparison therefore uses 30-minute and 10-minute index-futures effects as the nearest benchmarks.
