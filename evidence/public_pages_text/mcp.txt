 2 Create a key 
 Generate an API key at /account/mcp. Keys look like mcp_live_… — shown once, stored hashed, revocable anytime.

 Frequently asked
 Questions, answered 
 What is MCP?
 The Model Context Protocol — an open standard that lets AI clients like Claude Code, Claude Desktop, and Cursor call external tools. George exposes its live market-intelligence reads as MCP tools over one authenticated HTTP endpoint, so your agent can pull dealer positioning or institutional flow mid-conversation.
 Do GeorgeFi app subscriptions include MCP?
 No. MCP is a separate product line with its own plans (Indie, Pro, Enterprise). A Pup, Bob, or SPX app subscription does not grant MCP access, and an MCP subscription does not unlock the app.
 What are the quotas, and what happens at the limit?
 Indie includes 10,000 calls per month across light and medium tools; Pro includes 100,000 calls across all tools; Enterprise is unlimited. The quota resets at 00:00 ET on the first of each month. Past your quota, calls return HTTP 429 with the exact reset time, a Retry-After header, and links to upgrade or request an extension. Your agent can check usage any time with the free get_quota_status tool (never counted against the quota), every metered response carries X-MCP-Quota-Remaining and X-MCP-Quota-Reset headers, and /account/mcp shows the month at a glance. Heavy tools on Indie return a clear entitlement error rather than counting against your quota.
 Can my agent buy more calls mid-month?
 Yes, when credits are enabled: get_additional_credits buys extra calls for the current month in whole blocks priced per plan (dryRun shows the live block size and price), charged to the card already on your MCP subscription — no card is collected in the tool call. You always name a budgetUsd cap, dryRun: true returns a quote without charging, an identical request within ten minutes is replayed rather than charged twice, and per-purchase and per-month caps apply. Purchased calls expire with the month. The same purchase is available on /account/mcp.
 How fresh is the data?
 Tools read the same live engine state the GeorgeFi cockpit renders — dealer GEX from the live websocket cache, flow events as they're detected, and George's most recent analysis cycle. Responses carry timestamps and freshness metadata so your agent can tell live from off-hours state.
 How are API keys secured?
 Keys are shown once at creation and stored hashed — we cannot recover a lost key, only issue a new one. You can hold up to 10 active keys and revoke any of them instantly at /account/mcp. Send keys via the Authorization header; a ?auth= query fallback exists for clients that cannot set headers.
 Can I pay per call without a subscription?
 That is the x402 rail: agent-native per-call payments in USDC on Base, priced per tool class. The discovery endpoint is live today so agents can already enumerate tools and prices; per-call settlement is rolling out.
