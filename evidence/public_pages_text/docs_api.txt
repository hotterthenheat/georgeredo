 GET /api/nerve/calibration
 Latest calibration scoreboard for the Nerve 30-minute ^SPX probabilistic forecast. Returns Brier score, Expected Calibration Error (ECE), pinball loss, PIT-KS test, and reliability metrics plus drift status. Observer-only — the bot does NOT consume this forecast for trade execution. Honest empty-state envelope when no active model ( reason: 'no_active_model' ). 
 Request
 GET https://georgefi.trade/api/nerve/calibration 
 Response
 {
 "ticker": "^SPX",
 "modelVersion": null, // or "spx-forecast-gbm-v1" when active
 "window": [], // calibration rows; empty when no active model
 "drift": null, // drift report; null when insufficient data (NaN-tolerant)
 "reason": "no_active_model", // present when window is empty
 "fetchedAt": "2026-05-23T16:58:21.490Z"
} 
 Usage Examples
 JavaScript/TypeScript 
 // Get George's latest analysis
const response = await fetch('https://georgefi.trade/api/analysis');
const data = await response.json();
console.log('Market Status:', data.marketStatus);
console.log('Active Signals:', data.signals.length);
console.log('Latest Decisions:', data.decisions); 
 Python
 import requests
# Get portfolio data
response = requests.get('https://georgefi.trade/api/portfolio')
portfolio = response.json()
print(f"Open Trades: {len([t for t in portfolio['trades'] if t['status'] == 'OPEN'])}")
print(f"Total P&L: ${portfolio['summary']['totalPnL']:.2f}") 
 cURL
 # Get ICT analysis for SPY
curl "https://georgefi.trade/api/ict-analysis?ticker=SPY"
# Get performance metrics
curl "https://georgefi.trade/api/performance" 
 Important Notes
 Read-Only: All endpoints are read-only. No trading execution endpoints are exposed. 
 Security: Firestore database is secured and not directly accessible. All data access must go through these API endpoints, which use server-side authentication. 
 Rate Limits: Please be respectful with request frequency. No official limits, but avoid excessive polling. 
 Data Freshness: Analysis data updates every minute during market hours. Portfolio data is real-time. 
 Market Hours: Most endpoints work 24/7, but analysis is most relevant during market hours (9:30 AM - 4:00 PM ET).
