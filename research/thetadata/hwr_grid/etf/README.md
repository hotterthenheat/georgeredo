# High-win-rate short-premium grid: SPY / QQQ / IWM 0DTE at measured NBBO

Pre-registered grid search (TRAIN-only selection, fixed TEST window) over short straddles/strangles and iron condors on the
same-day expiry of SPY, QQQ and IWM, priced at the 1-minute NBBO of the local ThetaData dataset
(`research/thetadata/dataset`).  Design: `PREREGISTRATION.md`.  Results: `RESULTS.md`.  Research note:
`research_notes/High win rate 0DTE lanes/empirical_etf_short_premium_grid.md`.

## Files

| file | role |
|---|---|
| `PREREGISTRATION.md` | the grid, fills, rules, statistics and gate, written before any TEST computation; amendment A1 (ATM strike requires spot inside the stored band) |
| `common.py` | constants, calendars (FOMC from `vol_filters/events.csv`, month-end = last session of the month), quote cube per ticker-session, bootstrap |
| `reproduce.py` | sanity check: recomputes the published T-A lane of `straddle_nbbo/RESULTS.md` from the dataset → `results/reproduction.*` |
| `engine.py TICKER PERIOD` | per-trade simulation (every structure-k × entry × TP × stop × exit, plus random-entry baseline trades) → `$HWR_WORK/trades_*.parquet` |
| `analyze.py train` | TRAIN aggregation and selection → `results/grid_train.csv.gz`, `results/selection_train.json` |
| `analyze.py test` (`analyze_test.py`) | TEST aggregation, selections on TEST, random baselines, gate, chance count, reality check, marginal effects, coverage |
| `diagnostics.py` | post-hoc (not pre-registered) diagnostics of the hold-to-expiry result: settlement price, after-hours exercise, last-5-minute straddle |
| `report.py` | builds `RESULTS.md` from `results/` |
| `results/` | `grid.csv.gz` (one row per scope × configuration with TRAIN and TEST metrics), `selected_test.csv`, `selected_by_year.csv`, `baselines.csv`, `random_minutes.csv.gz` (the committed random-entry contract-day list), `marginal_effects.csv`, `wr_vs_expectancy.csv`, `coverage.csv`, `grid_test_summary.json`, `train_reality_check.json` (the same full-grid statistics computed by `python3 analyze_test.py dryrun` on TRAIN only, SPY/QQQ/pooled, before IWM existed), `diag_*.csv` |

Per-trade data (about 35 MB of parquet for the three tickers) stays outside the repo in `$HWR_WORK` (default `<scratchpad>/hwr_grid/`); it is
regenerated by `engine.py` in about 30–45 s per ticker-period.

## Reproduce (no network, no ThetaData key; polars + numpy)

```bash
cd research/thetadata/hwr_grid/etf
python3 reproduce.py
for t in SPY QQQ IWM; do python3 engine.py $t TRAIN; done
python3 analyze.py train                 # writes selection_train.json (TRAIN only)
for t in SPY QQQ IWM; do python3 engine.py $t TEST; done
python3 analyze.py test
python3 diagnostics.py
python3 report.py
```
